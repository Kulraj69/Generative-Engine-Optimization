# AnswerLens

## Description

AnswerLens audits the public evidence layer of B2B SaaS websites. It checks crawlable URLs, `llms.txt`, metadata, pricing, comparison, proof, and buyer-question surfaces, then turns visible gaps into a source-backed report.

## Website

- https://app.sfdj.net/

## Type

- Web application
- Public-evidence audit and report workflow

## License

Proprietary SaaS. Public scans are available from the website; paid evidence reports are one-time digital purchases.

## Key Features

- Checks whether public SaaS pages expose evidence a buyer can inspect.
- Reviews crawlability, metadata, `llms.txt`, pricing, comparison, proof, and buyer-question coverage.
- Produces a free public-evidence scan before the optional paid report path.
- Publishes a machine-readable `llms.txt` file at `https://app.sfdj.net/llms.txt`.

## Installation

No installation is required. Run a scan from the public website.

## Basic Usage

1. Open `https://app.sfdj.net/`.
2. Enter a public B2B SaaS website URL.
3. Review the free public-evidence scan.
4. Use the paid report path only when the public scan shows a gap worth turning into implementation work.
